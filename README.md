# CampusBuzz - Campus Event Management

A simple PHP & MySQL web app for managing college events and student registrations.

## Setup
1. Start Apache and MySQL (XAMPP / MAMP).
2. Import `database.sql` in phpMyAdmin.
3. Update DB credentials in `db.php` if needed (default: port `8889`, user `root`, pass `root`).
4. Open `http://localhost/Campus-Event-Minimal` in your browser.

To make an admin user, sign up normally and change `role` to `admin` in the `users` table.
